 Protioso Gerenciamento de Pickups (PGP) 1.3, por [VGS]Protioso_OC

 
	Introdução

 PGP veio para lhe facilitar. Com um gerenciamento fácil e rápido, você poderá fazer scripts rápidos, bem acabados e com diversas formas e alternativas 
de trabalho. Seu uso é muito simples, e conta com funções diversificadas.



	Explicando funções


 AVISO: Não se esqueça que as funções abaixo, descritas, só funcionam com as pickups do sistema PGP (criadas pelas funções do include PGP)!

 IMPORTANTE: Antes de começar usar as demais funções do PGP, não esqueça de colocar as funções "public JogadorEmPickup(playerid, pgpid)" e
 "public pgp_JogadorEntrouEmRaio(playerid, pgpid)". 
 Funções à colocar:
 
 public pgp_JogadorEmPickup(playerid, pgpid) 
 {
	return 1;
 }
 Esta função serve para detectar quando um jogador pegar uma pickup, criada pelo sistema PGP, obviamente.

 
 public pgp_JogadorEntrouEmRaio(playerid, pgpid)
 {
	return 1;
 }
 Esta função serve para detectar quando um jogador entrar em um raio de uma pickup (pickups com raio: pgp_CriarPickupR e pgp_CriarPickupREx),
 criada pelo sistema PGP, obviamente.

-------------------------------------------


	Funções gerais


-   pgp_CriarPickup(pmodeloid, tipo, Float:x, Float:y, Float:z);

 Cria uma PGP pickup normal.
 pmodeloid: Modelo ID da pickup;
 tipo: Tipo de pickup*;
 X: Ponto flutuante X (coordenada);	
 Y: Ponto flutuante Y (coordenada);	
 Z: Ponto flutuante Z (coordenada).


-   pgp_CriarPickupEx(pmodeloid, tipo, Float:x, Float:y, Float:z, mensagem[], estilogametext);

 Cria uma PGP pickup que, quando o jogador a toca, envia um GameText com mensagem definida.
 pmodeloid: Modelo ID da pickup;
 tipo: Tipo de pickup*;
 X: Ponto flutuante X (coordenada);	
 Y: Ponto flutuante Y (coordenada);	
 Z: Ponto flutuante Z (coordenada);
 mensagem: Mensagem a ser enviada pelo GameText;
 estilogametext: Estilo do GameText a ser apresentado.


-   pgp_CriarPickupR(pmodeloid, tipo, Float:x, Float:y, Float:z, Float:raio);	

 Cria uma PGP pickup que, quando o jogador o jogador entra em seu raio, é identificado.
 pmodeloid: Modelo ID da pickup;
 tipo: Tipo de pickup*;
 X: Ponto flutuante X (coordenada);	
 Y: Ponto flutuante Y (coordenada);	
 Z: Ponto flutuante Z (coordenada);
 raio: Ponto flutuante.


-  pgp_CriarPickupREx(pmodeloid, tipo, Float:x, Float:y, Float:z, Float: raio, mensagem[], estilogametext);

 Cria uma PGP pickup que, quando o jogador entra em seu raio, é identificado e envia um GameText com mensagem definida.
 pmodeloid: Modelo ID da pickup;
 tipo: Tipo de pickup*;
 X: Ponto flutuante X (coordenada);	
 Y: Ponto flutuante Y (coordenada);	
 Z: Ponto flutuante Z (coordenada);
 raio: Ponto flutuante;
 mensagem: Mensagem a ser enviada pelo GameText;
 estilogametext: Estilo do GameText a ser apresentado.


- pgp_PegarPosicaoPickup(pgpid, &Float:x, &Float:y, &Float:z);
 
 Pega as posições X, Y e Z de uma pickup já criada.
 pgpid: ID (interno) da pickup;
 X: Ponto flutuante X (coordenada);	
 Y: Ponto flutuante Y (coordenada);	
 Z: Ponto flutuante Z (coordenada).


-  pgp_JogadorNaPickup(playerid, pgpid);

 Checa se o jogador está na pickup (criada pelo PGP) determinada. Retorna a 1 se o jogador estiver, na pickup, e a 0 se não estiver.
 playerid: ID do jogador;
 pgpid: ID da pickup que você quer checar se o jogador está.



-  pgp_JogadorPickup(playerid);
 
 Pega o ID da pickup em que o jogador está posicionado. Retorna o ID da pickup, ou -1 caso o jogador não esteja em uma pickup.
 playerid: ID do jogador.


-  pgp_JogadorEstaEmPickup(playerid);

 Checa se um jogador está em uma pickup (PGP).
 playerid: ID do jogador.


-  pgp_DesativarPickup(pgpid);

 Desativa uma pickup do sistema PGP (não destrói).
 pgpid: ID da pickup a ser desativada.


-  pgp_DestruirPickup(pgpid);

 Destrói e desativa uma pickup do sistema PGP.
 pgpid: ID da pickup a ser destruída.


-  pgp_DestruirPickupEx(pgpid);

 Destrói e semi-desativa uma pickup do sistema PGP. A pickup pode ser recriada novamente com a função pgp_RecriarPickup(pgpid).
 pgpid: ID da pickup a ser destruída e semi-desativada.


-  pgp_RecriarPickup(pgpid);

 Recria uma pickup semi-desativada.
 pgpid: ID (interno) da pickup a ser desativada.


-  pgp_MudarModelo(pgpid, novomodeloid);

 Muda o modelo ID de uma pickup.
 pgpid: ID da pickup;
 novomodeloid: Novo ID do modelo de pickup desejado. 


-  pgp_MudarTipo(pgpid, novotipo);

 Muda o tipo* de pickup.
 pgpid: ID da pickup;
 novotipo: Novo tipo* de pickup;


-  pgp_MudarEstiloGT(pgpid, novoestilo);

 Muda o estilo de GameText de uma pickup com GameText ativo.
 pgpid: ID da pickup;
 novoestilo: Novo estilo de GameText.


-  pgp_MudarMensagem(pgpid, novamensagem[]);

 Muda a mensagem de uma pickup com GameText ativo. 
 pgpid: ID da pickup;
 novamensagem: Nova mensagem a ser colocada.


-  pgp_AdicionarMensagem(pgpid, mensagem[]);

 Adiciona uma mensagem a uma pickup que está com GameText inativo.
 pgpid: ID da pickup;
 mensagem: Mensagem a ser colocada;


-  pgp_MudarRaio(pgpid, Float:novoraio);

 Muda o raio de uma pickup que já tem raio ativo.
 pgpid: ID da pickup;
 novoraio: Ponto flutuante do novo raio.


-  pgp_AdicionarRaio(pgpid, Float:raio);
 
 Adiciona um raio em uma pickup que está com raio inativo.
 pgpid: ID da pickup;
 raio: Ponto flutuante do raio a ser colocado.


-  pgp_PickupExiste(pickup);

 Checa se uma pickup pertence/existe no sistema PGP. Retorna a 1 se a pickup pertence/exsite e a 0 caso não pertença/exista.
 pgpid: ID da pickup a ser checada.


-  pgp_PickupPGPOn(pgpid);

 Checa se uma pickup (PGP) está em funcionamento. Retorna a 1 se a pickup está em funcionamento e a 0 caso não esteja.
 pgpid: ID da pickup a ser checada.


-  pgp_JogadorEmPickupModelo(playerid, pmodeloid);

 Checa se um jogador está em uma pickup de modelo igual ao definido. Retorna a 1 se o jogador estiver, na pickup de mesmo modelo, e a 0 se não estiver.
 playerid: ID do jogador;
 pmodeloid: ID do modelo da pickup.
   

-  pgp_JogadorRaio(playerid);

 Retorna ao ID da pickup que o jogador está em seu raio. Retorna a -1 caso o jogador não se encontra em nenhum raio.
 playerid: ID do jogador.


-  pgp_MensagemPickup(pgpid);

 Retorna à mensagem (string) da pickup.
 pgpid: ID da pickup.
